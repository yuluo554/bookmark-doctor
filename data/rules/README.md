# data/rules/ — 降级规则库

M1 起收录 `ruleset.json`：中文站点反爬响应特征的**版本化降级规则库**（含探测参数、追踪参数表、短链映射、分档阈值等单点口径），由 `tools/gen_ruleset.py` 生成/校验。

硬纪律（详见 `plan/04` §2.3、`plan/05`）：

- 每条降级规则必须携带**实测记录锚点**（观测 ID + 查证状态），锚点解析不到或未复核 → **拒绝被引擎加载**，进"未启用清单"；
- 规则包为**冻结产物**：禁手改，改数据走生成器整目录重生成 + `--check` 位级一致；
- 全部可调数值**只在本目录定义一次**，引擎/基准/测试不得出现第二份。

状态：✅ M1 已产出（ruleset v1：probe 参数 + 4 条降级规则全挂 verified 锚点 + 追踪参数表 + aging 分档 + similarity 阈值；版本号内容哈希派生；`--check` 位级一致双解释器实测通过）。
