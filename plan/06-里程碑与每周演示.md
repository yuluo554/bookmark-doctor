## 里程碑间纪律（每棒通用）

1. **收尾顺序固定**：DoD 验证 → plan/00·05(如需)·06 状态回写 → 写 `HANDOFF-M<next>` → commit →（有远端则 push 等 CI 绿）。
2. HANDOFF 六节齐：当前进度+证据 / 下一棒待办 / 既定口径 K 清单 / 本机环境坑 / DoD checklist / 关键命令速查；**库内一律相对路径**。
3. 每棒收尾**复跑双基线**（全量测试 + 基准，M4 起）防回退。
4. 未接远端期间一切 CI 结论写"本地等价校验（未接远端，CI 待首推验证）"。
5. 新增/改写的守门做一次**变异验证**；新增脚本**必带编码守卫**（K8）。
6. 测试计数、命令计数等"会随动作增长的量"，文档引用写"取值方式 + 快照环境"，不抄写裸数字。
