# plan/03 - 架构与技术选型

> 状态：已定稿（2026-10-15，sprint 阶段 0）。本文件定"系统的形与骨"；模块内部细节见 `plan/04-模块详设.md`。

## 1. 系统形态与数据流

**形态**：纯本地单命令族 CLI（`bookmark-doctor`）+ 本地单文件 HTML 报告；零服务端、零登录、零上传。

**数据流（一条链）**：

```
bookmarks.html / Bookmarks(JSON) ──► 解析层（M2）──► 统一中间表示 UIR（tree.json）
                                                        │
  降级规则库 ruleset.json ──► 检测引擎（M3）────────────┤
                                                        ├──► 判定结果（check.json）
  URL 规范化（单点实现）──► 去重引擎（M3）───────────────┘
                                                        │
                                                        ▼
                                    报告渲染（M5，单文件 HTML）+ 一键导回（M5，Netscape HTML）
```

- `<pkg> run` 编排全链路（导入→检测→去重→报告→导回）一条命令出结果；各阶段也可单独调用（import / check / dedupe / report / export）。
- 所有中间产物为**确定性 JSON**（排序稳定、无时钟、无随机）；报告为**自包含单文件 HTML**（断网可开）。

## 2. 统一中间表示（UIR）—— 模块① 的产物、模块②③④ 的公共输入

草案（M2 实现时冻结，字段名进"既定口径 K 清单"）：

```json
{
  "schema": "bookmark-doctor/tree-v1",
  "sources": ["来源文件名或浏览器标识"],
  "bookmarks": [
    {
      "id": "确定性 ID（来源 + 文件内序号推导，可复现）",
      "title": "标题原文（缺失时 null）",
      "url": "URL 原文（永不改写）",
      "add_date": 1735689600,          // epoch 秒；缺失 = null（落"未知"，不猜补）
      "folder": ["收藏夹", "子目录"],   // 层级路径
      "source": "来源标识（哪个文件/浏览器）"
    }
  ]
}
```

纪律：
1. **原始 URL 永不改写**（规范化只用于比较键，导回时导出的是原始 URL 或用户确认保留项）；
2. `null` ≠ 猜测：缺失字段一律 `null`，渲染层显示"未知"；
3. 序列化：`sort_keys` 稳定排序、LF 行尾、无时间戳字段（需要日期的字段由显式参数注入，见 §7）。

## 3. 技术选型（含弃选理由）

| 维度 | 选择 | 弃选与理由 |
|---|---|---|
| 语言/版本 | **Python ≥ 3.8**，stdlib-only | 本机底线解释器 3.8.8 可守；零依赖红线；3.8 兼容写法成本低（禁 3.9+ 语法糖，见 §6） |
| CLI 框架 | `argparse` | 弃 click/typer：引入第三方依赖违背"零依赖"定位 |
| HTTP 探测 | `urllib.request` + 自写 redirect/header 控制 | 弃 requests/httpx：零依赖；且自写 handler 让"跟随跳转/超时/重试"显式可审计 |
| HTML 解析 | `html.parser`（stdlib） | 弃 lxml/bs4：Netscape 书签格式极规整，标准库足够；少一份依赖少一份风险 |
| 去重相似度 | `difflib.SequenceMatcher` | 仅作辅助提示，标准库足够；阈值进 ruleset.json |
| 内容/数据格式 | JSON（数据与产物）、单文件 HTML（报告）、Netscape HTML（导回） | 全标准库可读写 |
| 打包/构建 | `setuptools`（PEP 621 pyproject） | 弃 poetry/hatch：构建面最小化；3.8 也能 build（setuptools 自动解析兼容版本） |
| 测试 | `pytest`（仅 dev extra） | 测试期依赖明确进 `[dev]`；测试面 = 安装面 = README 指令面（见 §10） |
| LLM | **不使用** | 决策记录 D14：全部结论确定性产生，无解析兜底需求 |
| 并发 | 首期**串行**探测（降频优先、顺序确定） | 并发为缓议扩展；串行让降频与确定性都最简单 |

## 5. CI 策略（三矩阵）

- **矩阵**：`windows-latest × {3.8, 3.12}` + `ubuntu-latest × 3.12`。
  - 理由：旧解释器（3.8，本机底线通道）在 windows 守；POSIX 通路走 ubuntu 3.12（ubuntu 新镜像对 3.8 支持存疑，暂不硬凑四矩阵，首推实测后按实况补记）。
- **步骤**：checkout（`fetch-depth: 0`，为后续历史扫描类守门预留）→ setup-python → `python -m pip install -e ".[dev]"` → `python -m pytest -q` → 冒烟三条：**裸命令** `bookmark-doctor --version` / `bookmark-doctor --selftest` + **模块形态** `python -m bookmark_doctor --selftest`（两条通路分别冒烟，防"我们自己的包没进安装面"类缺陷）。
- **env**：`PYTHONUTF8=1`（救 CI 全部步骤的编码盲区）、`PYTHONDONTWRITEBYTECODE=1`（防 pyc 偶发损坏）。
- **诚实口径**：当前**未接远端，CI 从未实跑**——一切 CI 结论写"本地等价校验（未接远端，CI 待首推验证）"；发布里程碑据实补记真实 run。

## 6. 编码纪律（全入口，含 tools/）

1. 所有会打印的执行入口（主 CLI 与 `tools/` 下每个脚本，**含里程碑后期新增的**）第一步调用 `ensure_utf8_stdio()`：按 `stream.encoding` 探针决定是否 reconfigure 为 UTF-8；**中文控制台 cp936 保持不动**；判定不了的流不动。
2. 子进程输出解码一律显式 `encoding="utf-8", errors="replace"`（无环境变量可替代），落盘前 `.replace("\r\n", "\n")` 归一。
3. 代码文件一律 LF（`.gitattributes: * text=auto eol=lf`）；写文件用 `newline="\n"` / `write_bytes`（`Path.write_text(newline=)` 是 3.10+ 参数，3.8 上禁用）。
4. 非 ASCII 输出在小值探针下测试（cp1252 `TextIOWrapper(BytesIO())` 复现 + `PYTHONIOENCODING=cp1252` 子进程真跑），本机即可复现 CI 编码盲区。

## 7. 确定性纪律

1. 生成器（fixtures / ruleset）：**禁 stdlib `random`、禁 set 迭代序、禁系统时钟**——自研 splitmix64 确定性 RNG；落盘产物无时间戳；两次运行逐字节一致并配 `--check` 守门。
2. 需要"日期"语义的产物字段（如 check.json 的探测日期）**由显式参数注入**（`--probe-date`，基准传固定值），保证"同参数 → 同字节"；用户日常运行默认取当天日期（属输入参数而非输出噪声）。
3. 目录遍历后一律**显式 sort** 再处理（`os.walk` 顺序不稳定）。
4. 报告渲染给定同一组输入（含探测日期参数）时逐字节可复现。

## 8. 退出码契约（锁定进测试）

| 场景 | 退出码 |
|---|---|
| CLI 正常运行完成（含"体检发现问题"——结果在报告里，不是错误） | **0** |
| CLI 用法错误 / 未知参数 / 无参数（打印帮助提示动作缺失） | **2** |
| CLI 输入不可用（文件不存在、解析失败——题面"显式报错退出"） | **2** |
| 基准脚本：全部达标 | **0** |
| 基准脚本：未达标（含"未启用套件"空分母分支） | **1** |
| 基准脚本：用法错误 / `--only` 传未知名 | **2** |
| `--selftest`：自检通过 / 失败 | 0 / 1 |

> "失败件 ≠ 违规"同源纪律：一份文件**不能用**（exit 2）与"能用但其中某些条目被判有问题"（exit 0，问题进报告）是两种不同语义，不得混用（详见 plan/04 §2.4）。

## 9. 单点口径清单（"谁说了算"）

全部可调参数与规则数据集中在 **`data/rules/ruleset.json`** 一个文件（分节）：

| 节 | 内容 | 举例（初值，M1/M3 实测复核后冻结） |
|---|---|---|
| `probe` | 超时秒数 / 重试次数 / 降频间隔 / 跳转上限 / User-Agent 形态 | timeout=8s, retries=1, delay=1.0s, redirect_max=5 |
| `degrade_rules` | 站点降级规则（每条挂实测锚点） | 知乎 403 → review；521 → review …… |
| `tracked_query_params` | 去重时剥离的追踪参数表 | `utm_*` / `share_token` / `spm` / `scm` / `from` …… |
| `shortlink_known` | 已实测短链→长链映射 | 每条挂实测锚点 |
| `aging` | 长期未访问分档阈值 | tiers_days=[365, 730, 1095] |
| `similarity` | 标题相似提示阈值 | threshold=0.9（仅提示不自动删） |

- 引擎 / 基准 / 测试源码中**不得出现第二份**上述数值或平台主机名词面（零字面量门禁，M3 落地：扫描 `src/` 与后续前端源码；豁免口径写死）；
- 规则包版本号由 manifest **派生**（内容哈希），不在代码里手写常量。

## 10. 测试与安装面纪律

- **测试面 = 安装面 = README 指令面**：README 快速开始的安装命令（`pip install -e ".[dev]"`）就是 CI 与干净环境验证的唯一通路；测试真 import 的库必须在 `[dev]` extras 里。
- **两条命令通路都要冒烟**：`python -m bookmark_doctor ...`（模块形态）与裸 `bookmark-doctor ...`（console script）；CI 与 README 都要覆盖。
- 新增守门做一次**变异验证**（故意弄坏被测行为 → 门必须变红）；不产生失败的门是假门。
- 失败路径测试（缺文件 / 坏格式 / 输入输出不可写）与退出码断言同等重要。

## 11. 交付形态与打包（缓议）

- 首期交付：源码 + `pip install -e .`（或 `pip install .`）本地安装 + 克隆即用的数据资产；Release 附产物（sdist/wheel + 便携源码 zip）在 M6 定案。
- 冻结 exe（PyInstaller）列为**缓议**：若 M5 有余量则做"单文件 CLI exe"作为可选下载；不做则为显式记录的非目标（"未做"与"决定不做"是两回事）。
